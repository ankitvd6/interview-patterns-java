# Interview Patterns Java

A minimalist GitHub Pages site for Java-focused DSA and interview pattern notes.

## GitHub Pages

This site is designed for GitHub Pages with Jekyll. Publish from the `main`
branch and GitHub will render Markdown files in `_notes/` as web pages.

## Add a New Note

Create a Markdown file in `_notes/` with front matter:

```yaml
---
title: Two Pointers
section: Arrays
summary: Fast review notes for two-pointer patterns.
tags: [arrays, java]
order: 20
---
```

The home page will list it automatically.
